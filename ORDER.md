# Order Template

Copy this message after payment:

```
PRODUCT: [Canvas / Playbook / Bundle / Checklist / Templates / Decision Tool]
AMOUNT_USD: [29 / 79 / 129 / 19 / 39 / 49]
PAYMENT_METHOD: [USDT-ERC20 / BTC-ONCHAIN / BTC-LIGHTNING]
TX_ID: [paste transaction hash or Lightning payment hash]
EMAIL: [your email for delivery]
NOTES: [optional]
```

## Example

```
PRODUCT: Complete Bundle
AMOUNT_USD: 129
PAYMENT_METHOD: USDT-ERC20
TX_ID: 0xabc123...
EMAIL: buyer@example.com
NOTES: Prefer PDF format
```

Send this after payment. Delivery starts after confirmation.
